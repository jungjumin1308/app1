# 마음이음

엄마와 아빠가 서로의 마음을 차분하게 나눌 수 있도록 기획한 가족 대화 앱의 화면 시제품입니다. 첨부 기획서의 ‘접속 → 이름 작성 → 채팅방 입장 → 편안한 대화’ 흐름을 반영했습니다. 화해를 보장하거나 대화를 강요하는 서비스는 아닙니다.

## 파일 2개
- `index.html`: 디자인, 로고, 화면 동작이 모두 포함된 웹페이지
- `README.md`: 실행 방법 및 구현 범위 안내

## 반영한 요청
1. 접속 시 하트 심볼과 ‘마음이음’ 로고가 먼저 나타납니다. 약 1.5초 후 시작 화면으로 이동하며, 바로 시작하기 버튼으로 건너뛸 수도 있습니다. 로고는 별도 이미지 없이 표시됩니다.
2. 앱 화면에는 나무위키 형태의 카테고리, 목차, 사이드바가 없습니다. 이름 입력과 대화방 중심으로 구성했습니다. GitHub가 README에 표시하는 자체 탐색 UI는 앱 화면과 별개입니다.

## GitHub Pages로 사용하기
1. 두 파일을 저장소의 최상위 폴더에 업로드합니다. `index.html` 이름을 유지하세요.
2. 저장소의 Settings → Pages에서 배포 소스를 Deploy from a branch로 선택합니다.
3. 파일을 올린 브랜치(일반적으로 main)와 /(root)를 선택하고 저장합니다.
4. 배포가 완료되면 Pages 화면에 표시되는 사이트 주소로 접속합니다. 저장소 정책이나 계정 권한에 따라 Pages 사용 가능 여부가 다를 수 있습니다.

파일을 내려받은 뒤 `index.html`을 브라우저로 열어도 작동합니다. 별도의 설치나 API 키는 필요하지 않습니다.

## 사용할 수 있는 기능
- 접속 시 로고 표시
- 이름 입력 후 대화방 입장
- 메시지 입력 및 화면에 표시
- 같은 화면에서 말하는 사람을 바꿔 대화 시연
- 대화 주제 변경
- 쉬기 및 재개
- 나갈 때 대화 삭제 확인
- 모바일 대응 화면

## 중요한 한계
이 파일은 실제 온라인 메신저가 아닙니다. 두 휴대전화가 같은 대화방으로 연결되지 않으며, 계정·초대 링크·서버·데이터베이스·AI 답변·유해 표현 감지 기능도 없습니다. ‘상대방 (시연)’은 같은 화면에서 사용자가 직접 입력하는 기능이며 실제 상대방의 응답이 아닙니다.

메시지와 이름은 실행 중인 페이지 메모리에만 남습니다. 새로고침, 페이지 종료, 나가기 시 사라집니다. 서버나 브라우저 저장소에 대화 기록을 저장하지 않습니다. 정적 호스팅 업체의 접속 로그와 별개이며, 실제 개인정보를 다루기 위한 보안 검증을 마친 제품은 아닙니다.

실제 두 사람이 각자 접속하는 앱으로 확장하려면 사용자 인증, 방별 접근 권한, 실시간 전송 서버, 데이터 보관·삭제 정책 및 보안 점검이 필요합니다. 비밀 키를 공개 저장소나 HTML에 넣지 마세요.

## 수정하기
`index.html`에서 ‘마음이음’을 원하는 이름으로 변경할 수 있습니다. CSS의 `--green` 값을 바꾸면 대표 색상이 바뀝니다. 스크립트의 `topics` 배열에서 대화 주제를 수정할 수 있습니다.

## 안전한 대화 원칙
대화 참여와 중단은 당사자의 선택입니다. 앱의 사용이나 화해 결과는 자녀가 책임질 일이 아닙니다. 위협·폭력이 있다면 화해보다 안전을 우선하며, 긴급한 위험은 112에 도움을 요청하세요.
